Para lograr la estética de una pantalla E Ink, el diseño debe ser minimalista, de alto contraste, 
enfocado en la tipografía y sin animaciones fluidas. En las pantallas de tinta electrónica reales, las 
transiciones suaves consumen mucha energía y generan imágenes fantasma (ghosting), por lo que todo 
cambia de forma instantánea o con un destello rápido.
Aquí tienes un archivo CSS base diseñado para imitar perfectamente esa experiencia visual y táctil:

/* ==========================================================================
   E-INK BASE THEME
   ========================================================================== */

:root {
  /* Paleta de color: Simula el fondo grisáceo/arena del papel electrónico */
  --eink-bg: #f4f4f0;       
  --eink-text: #1a1a1a;     
  --eink-border: #222222;   
  --eink-accent: #555555;   
}
/* Modo Oscuro Opcional (Simulando modo inverso de un e-reader) */@media (prefers-color-scheme: dark) 
{
  :root {
    --eink-bg: #121212;
    --eink-text: #e0e0e0;
    --eink-border: #cccccc;
    --eink-accent: #888888;
  }
}
/* Configuración Global */
html, body {
  background-color: var(--eink-bg);
  color: var(--eink-text);
  font-family: "EB Garamond", "Georgia", "Times New Roman", serif; /* Tipografía estilo libro */
  line-height: 1.6;
  font-size: 18px;
  padding: 20px;
  max-width: 800px;
  margin: 0 auto;
  
  /* Elimina el suavizado excesivo para que la fuente se vea más "impresa" */
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
  
  /* Desactiva cualquier transición global para evitar fluidez tipo OLED */
  transition: none !important;
}
/* Tipografías e Impresión */
h1, h2, h3, h4 {
  font-family: "Helvetica Neue", "Arial", sans-serif; /* Títulos limpios sin serifa */
  color: var(--eink-text);
  font-weight: 700;
  margin-top: 1.5em;
  letter-spacing: -0.02em;
}

p {
  margin-bottom: 1.5em;
  text-align: justify; /* Estilo clásico de libro */
  text-justify: inter-word;
}
/* Enlaces y Botones */
a {
  color: var(--eink-text);
  text-decoration: underline;
  text-underline-offset: 4px;
  text-decoration-thickness: 2px;
}

a:hover {
  background-color: var(--eink-text);
  color: var(--eink-bg);
  text-decoration: none;
}

button {
  background-color: transparent;
  color: var(--eink-text);
  border: 2px solid var(--eink-border);
  padding: 8px 16px;
  font-family: sans-serif;
  font-weight: bold;
  cursor: pointer;
  
  /* Crucial: Sin transiciones CSS en los estados hover/active */
  transition: none; 
}

button:active {
  background-color: var(--eink-text);
  color: var(--eink-bg);
}
/* Elementos de Estructura e Imágenes */
hr {
  border: 0;
  border-top: 2px solid var(--eink-border);
  margin: 2em 0;
}

img {
  /* Filtro para forzar que las imágenes parezcan de periódico antiguo */
  filter: grayscale(100%) contrast(120%);
  border: 1px solid var(--eink-border);
  max-width: 100%;
  height: auto;
}
/* Bloques de código o datos */
pre, code {
  font-family: "Courier New", Courier, monospace;
  background-color: rgba(0,0,0,0.05);
  padding: 2px 6px;
  border: 1px dashed var(--eink-border);
}

## Claves del diseño E Ink aplicado a la web:

* Paleta #f4f4f0: El fondo de un Kindle nunca es blanco puro (#fff), tiene un tono ligeramente cálido 
o grisáceo que reduce la fatiga visual.
* Cero animaciones (transition: none): En una pantalla E Ink real, los elementos cambian de golpe. Al 
quitar las transiciones, el sitio web reaccionará con esa misma "antinatural" e instantánea velocidad 
digital.
* Filtro de imagen: El código CSS incluye un filtro que transforma automáticamente cualquier imagen de 
color a escala de grises con alto contraste, imitando los paneles de tinta tradicionales.
* Texto justificado: El uso de text-align: justify junto con una fuente Serif evoca inmediatamente la 
maquetación de un libro electrónico.
